# Daggerheart Tracker

A lightweight, installable resource tracker for Daggerheart characters.

## Stack

- React 19
- Vite
- Tailwind CSS 4
- Supabase (planned for optional authentication and cloud sync)

## Local development

```bash
npm install
npm run dev
```

The app is deliberately being built local-first. Supabase configuration is not required until cloud sync is added.
